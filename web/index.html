    UMSN-IDE Web
    
      
    엄슨(UMSN) 코드를 브라우저에서 바로 쓰고 실행합니다. 설치할 것은 없고,
        파이썬은 Pyodide (WebAssembly) 로 돕니다.
    
      
    
        
    F5 / Ctrl+Enter실행 (엄슨!)
    
        
    Shift+F5멈춰
    
        
    F6 / F7파이썬 코드 보기 / 엄슨 검사
    
        
    F1단어장
    
        
    F9어두운/밝은 테마
    
        
    Ctrl+Space자동 완성
    
        
    Ctrl+F / Ctrl+H / Ctrl+G찾기 / 바꾸기 / 줄로 이동
    
        
    Ctrl+/주석 넣기·빼기
    
        
    Tab / Shift+Tab들여쓰기 / 내어쓰기
    
        
    Ctrl+S내려받기
    
      
    
      
      
        
    • 영어 이름에는 빨간 물결 밑줄이 생깁니다. 오른쪽 클릭으로 사전 단어나 음역으로 바꿀 수 있습니다.
      • 
        
    • 넘파이·판다스·맷플롯립은 처음 쓸 때 자동으로 받아 옵니다. 그림은 콘솔에 나타납니다 (한글 글꼴: D2Coding).
      • 
        
    • 열린 .umsn 파일끼리 엄슨가져와 파일이름 으로 불러올 수 있습니다.
      • 
        
    • 티킨터(tkinter)·거북(turtle) 창은 브라우저에서 열 수 없습니다. 데스크톱 UMSN-IDE(pyumsn -e)를 쓰세요.
