# 엄슨(UMSN) 프로그래밍 언어

> 우리 학교 유행어 **'엄슨'** 으로 만든 프로그래밍 언어. 파이썬과 1:1로 대응되어 서로 변환할 수 있고,
> 파이썬 라이브러리를 그대로 쓸 수 있습니다.

```
엄슨하다 인사..하이름..다..한
    엄슨한 형"안녕, {이름}! 엄슨!"

엄슨마다 번호 엄속 엄범위..하1..고 4..다..한
    어엄슨 번호 ..나머지 2 ..같슨 0..한
        엄!..하번호..고 "짝수"..다
    슨엄..한
        엄!..하번호..고 "홀수"..다

엄!..하인사..하"엄슨"..다..다
```

위 코드는 아래 파이썬 코드와 **완전히 같습니다** (줄 번호까지 같음).

```python
def 인사(이름):
    return f"안녕, {이름}! 엄슨!"

for 번호 in range(1, 4):
    if 번호 % 2 == 0:
        print(번호, "짝수")
    else:
        print(번호, "홀수")

print(인사("엄슨"))
```

## 구성

| 이름 | 설명 |
|---|---|
| **엄슨 언어** (`.umsn`) | 파이썬의 예약어·내장 함수·메소드·문장부호를 엄슨 단어로 바꾼 언어 |
| **PyUMSN** (`pip` 패키지, 모듈 `pyumsn`) | 엄슨 ↔ 파이썬 변환기, 실행기, import 지원, 대화형 셸 |
| **`pyumsn`** (명령줄) | `run` / `topy` / `toumsn` / `check` / `ide` / `repl` / `words` |
| **UMSN-IDE** | **엄슨 언어로 작성된** Tkinter IDE ([`pyumsn/ide/umsn_ide.umsn`](pyumsn/ide/umsn_ide.umsn)) |

윈도우와 리눅스를 지원합니다 (파이썬 3.11 이상).

## 설치

```bash
pip install PyUMSN            # PyPI 에서 (기본, 의존성 없음)
pip install "PyUMSN[libs]"    # numpy, pandas, matplotlib 까지
```

소스에서 설치하려면:

```bash
git clone https://github.com/hyjys/UMSN-Lang.git
cd UMSN-Lang
pip install .
```

- IDE 와 Tkinter 예제에는 Tkinter 가 필요합니다. 윈도우용 파이썬에는 기본으로 들어 있고,
  리눅스에서는 `sudo apt install python3-tk` (데비안/우분투) 처럼 설치하세요.
- 한글 글꼴(D2Coding, 나눔고딕코딩, 맑은 고딕, Noto Sans CJK KR 중 하나)이 있으면 IDE 가 자동으로 씁니다.

## 명령줄 도구 `pyumsn`

```bash
pyumsn run 안녕.umsn [인자...]      # 엄슨 실행 (임시 .py 를 만들어 실행 → 끝나면 삭제)
pyumsn 안녕.umsn                    # run 줄임
pyumsn run --keep 안녕.umsn         # 임시 .py 를 남김 / --show-py : 변환된 코드 먼저 보기
pyumsn topy 안녕.umsn               # 엄슨 → 파이썬 (안녕.py)
pyumsn topy 폴더/ -o 출력폴더/      # 폴더째 변환, -o - 는 화면으로
pyumsn toumsn hello.py              # 파이썬 → 엄슨 (hello.umsn)
pyumsn toumsn hello.py --keep-symbols   # 기호( ) : , 는 ASCII 그대로 (순한맛)
pyumsn check 안녕.umsn              # 영어 이름 등 검사
pyumsn ide [파일.umsn]              # UMSN-IDE
pyumsn repl                         # 엄슨 대화형 셸 (엄>>>)
pyumsn words -s print               # 단어장 검색
pyumsn words --translit polyfit     # 영어 이름 → 엄슨 음역
pyumsn words --markdown             # 전체 단어장 (docs/VOCABULARY.md)
```

`python -m pyumsn ...` 으로도 똑같이 쓸 수 있습니다.

## 문법

### 1. 단어 바꾸기

파이썬 예약어·내장 함수·자주 쓰는 메소드는 전부 엄슨 단어가 있습니다. 전체 목록: [docs/VOCABULARY.md](docs/VOCABULARY.md)

| 엄슨 | 파이썬 | 엄슨 | 파이썬 |
|---|---|---|---|
| `엄슨하다` | `def` | `엄!` | `print` |
| `어엄슨` | `if` | `엄?` | `input` |
| `슨엄어엄슨` | `elif` | `엄범위` | `range` |
| `슨엄` | `else` | `엄길이` | `len` |
| `엄슨한` | `return` | `엄목록` | `list` |
| `엄슨마다` | `for` | `엄슨` | `self` |
| `엄슨동안` | `while` | `__엄슨시작__` | `__init__` |
| `엄속` | `in` | `엄붙여` | `.append` |
| `엄슨틀` | `class` | `엄쪼개` | `.split` |
| `엄슨가져와` / `엄에서` / `엄으로` | `import` / `from` / `as` | `엄예외` | `Exception` |
| `엄슨참` / `슨엄거짓` / `엄없슨` | `True` / `False` / `None` | `엄값오류` | `ValueError` |
| `엄시도` / `엄슨예외` / `엄마침내` | `try` / `except` / `finally` | `어엄` | `lambda` |
| `엄그리고` / `엄또는` / `안엄슨` | `and` / `or` / `not` | `엄` | `pass` |

### 2. 문장부호 → `..` 기호어

`..` 뒤에 한글을 붙이면 기호가 됩니다. 앞말에 붙여 써도 됩니다.

| 엄슨 | 파이썬 | 엄슨 | 파이썬 | 엄슨 | 파이썬 |
|---|---|---|---|---|---|
| `..하` | `(` | `..다` | `)` | `..하다` | `()` |
| `..엄` | `[` | `..슨` | `]` | `..엄슨` | `[]` |
| `..어엄` | `{` | `..어슨` | `}` | `..어엄슨` | `{}` |
| `..한` | `:` | `..고` | `,` | `..은` | `=` |
| `..더해` | `+` | `..빼` | `-` | `..곱해` | `*` |
| `..나눠` | `/` | `..몫` | `//` | `..나머지` | `%` |
| `..같슨` | `==` | `..다르슨` | `!=` | `..크슨` / `..작슨` | `>` / `<` |
| `..더해은` | `+=` | `..화살` | `->` | `..바다코끼리` | `:=` |

- 속성 접근 `.` 과 `...` 은 그대로 씁니다: `엄슨.이름`.
- 기호어는 가장 긴 것부터 읽습니다. `..하` 뒤에 `다`로 시작하는 이름이 오면 띄어 쓰세요 (`f..하 다음..다`).
- ASCII 기호 `( ) : , =` 도 그대로 쓸 수 있습니다 (`pyumsn toumsn --keep-symbols` 결과).

### 3. 한글 전용 규칙 — 영어 이름 금지

엄슨 코드(문자열·주석 밖)의 **모든 이름은 한글·숫자·`_` 만** 쓸 수 있습니다. `print`, `count`, `점수x` 처럼
영문자가 섞인 이름은 변환기(`topy`)·실행기(`run`)·IDE 가 **실행 전에 거부**합니다.

```
엄슨 문법 오류 (영어.umsn 2줄 1칸): 영어 이름 'count' 는 쓸 수 없슨! 한글 이름을 쓰거나 '엄세어' 를 쓰세요.
    count ..은 점수 ..더해 1
    ^^^^^
```

단어장에 없는 영어 이름(라이브러리 함수 등)은 **음역**으로 씁니다. 표지 `외_` 뒤에 알파벳을 한 글자씩
한글로 적고(대문자는 앞에 `대`), 숫자와 `_` 는 그대로 둡니다. 음역은 원래 이름으로 정확히 되돌아갑니다.

| a | b | c | d | e | f | g | h | i | j | k | l | m | n | o | p | q | r | s | t | u | v | w | x | y | z |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 아 | 브 | 크 | 드 | 에 | 프 | 그 | 흐 | 이 | 즈 | 키 | 르 | 므 | 느 | 오 | 피 | 쿠 | 러 | 스 | 트 | 우 | 뷔 | 워 | 엑 | 야 | 지 |

예: `넘엄.외_피오르야프이트(...)` = `np.polyfit(...)`. `pyumsn words --translit 이름` 이나 IDE 의 **도움말 → 음역 도구**를 쓰면 편합니다.

파이썬 → 엄슨 변환(`toumsn`)은 사전에 없는 영어 이름을 자동으로 음역하므로, 결과는 항상 이 규칙을 지킵니다.
한글 이름이 엄슨 단어와 겹치면 `$엄슨` 처럼 `$` 를 붙여 "그냥 이름"으로 씁니다.

### 4. 문자열·주석·docstring 은 그대로

따옴표 안의 글자, `#` 주석, docstring 은 한 글자도 바뀌지 않습니다. 문자열 접두사만 한글로 씁니다.

| 엄슨 | 파이썬 |
|---|---|
| `형"안녕 {이름}"` | `f"안녕 {이름}"` (중괄호 안은 엄슨 코드) |
| `날"\d+"` | `r"\d+"` |
| `바"..."` / `유"..."` | `b"..."` / `u"..."` |
| `형날"..."`, `날바"..."`, `대형"..."` | `fr"..."`, `rb"..."`, `F"..."` |

### 5. UTF-8 전용

엄슨은 **무조건 UTF-8** 만 씁니다. UTF-8 이 아닌 파일(CP949, UTF-16 등)이나 다른 인코딩 선언이 있는 파일은
추측하지 않고 거부합니다. 모든 출력 파일은 BOM 없는 UTF-8 이고, 실행되는 프로그램도 UTF-8 모드
(`PYTHONUTF8=1`)로 돌아가서 윈도우 콘솔에서도 한글이 깨지지 않습니다.

## 파이썬 라이브러리 쓰기

모든 파이썬 라이브러리를 `엄슨가져와` 로 쓸 수 있고, 자주 쓰는 라이브러리는 `라이브러리 이름 + 엄슨` 단어가 있습니다.

| 엄슨 | 파이썬 | 자주 쓰는 단어 예 |
|---|---|---|
| `티킨터엄슨` (`티엄`) | `tkinter` (`tk`) | `창엄슨`=Tk, `버튼엄슨`=Button, `라벨엄슨`=Label, `배치엄슨`=pack, `엄슨루프`=mainloop, `글엄슨`=text, `명령엄슨`=command |
| `넘파이엄슨` (`넘엄`) | `numpy` (`np`) | `배열엄슨`=array, `영배열엄슨`=zeros, `범위배열엄슨`=arange, `평균엄슨`=mean, `모양바꿔엄슨`=reshape |
| `판다스엄슨` (`판엄`) | `pandas` (`pd`) | `데이터프레임엄슨`=DataFrame, `씨에스브이읽어엄슨`=read_csv, `머리엄슨`=head, `묶어보기엄슨`=groupby |
| `맷플롯립엄슨`, `파이플롯엄슨` (`플엄`) | `matplotlib`, `pyplot` (`plt`) | `그려엄슨`=plot, `보여엄슨`=show, `가로이름엄슨`=xlabel, `범례엄슨`=legend |
| `수학엄슨`, `랜덤엄슨`, `운영체제엄슨`, `시스템엄슨`, `시간엄슨`, `제이슨엄슨`, `거북엄슨` … | `math`, `random`, `os`, `sys`, `time`, `json`, `turtle` … | `제곱근엄슨`=sqrt, `랜덤정수엄슨`=randint, `잠자엄슨`=sleep |

```
엄슨가져와 넘파이엄슨 엄으로 넘엄
배열 ..은 넘엄.배열엄슨..하..엄1..고 2..고 3..슨..다
엄!..하넘엄.평균엄슨..하배열..다..다
```

`.umsn` 파일끼리도 import 됩니다: `엄슨가져와 계산기` → 같은 폴더의 `계산기.umsn`.

예제: [`examples/`](examples) — 안녕, 구구단, 클래스, 넘파이, 판다스, 맷플롯, 티킨터 계산기.

## UMSN-IDE

`pyumsn ide` 로 실행합니다. IDE 자체가 엄슨 언어로 작성되어 있습니다 ([`pyumsn/ide/umsn_ide.umsn`](pyumsn/ide/umsn_ide.umsn)).

- **엄슨 구문 강조** — 예약어, 내장 함수, 라이브러리 단어, `..` 기호어, `엄!`, 음역어, 문자열, 주석, 숫자를 색으로 구분
- **실시간 한글 전용 검사** — 영어 이름에 빨간 밑줄, 오른쪽 클릭 → 사전 단어/음역으로 바꾸기
- **`엄슨!` 버튼 (F5)** — 실행 결과가 아래 콘솔에 실시간 표시, `입력 ▸` 칸으로 `엄?`(input) 에 답하기, `■ 멈춰` (Shift+F5)
- 오류 줄 클릭 → 해당 줄로 이동, 오류 메시지는 엄슨 이름으로 (예: `엄영나누기오류`)
- 줄 번호, 현재 줄 강조, 괄호 짝 표시 (`..하`/`..다` 포함), 자동 들여쓰기 (`..한` 뒤), Tab/Shift+Tab, 주석 토글 (Ctrl+/)
- 여러 탭, 새로 만들기/열기/저장, 최근 파일, 저장 안 한 변경 경고
- 자동 완성 (Ctrl+Space), 엄슨 단어장 패널 (F1, 검색 + 두 번 눌러 넣기)
- 파이썬 코드 보기 (F6), 엄슨 검사 (F7), `.py` 가져오기/내보내기
- 찾기/바꾸기 (Ctrl+F), 줄로 이동 (Ctrl+G), 어두운/밝은 테마 (F9), 글자 크기 (Ctrl +/−, Ctrl+휠)

## 파이썬에서 쓰기

```python
import pyumsn

pyumsn.umsn_to_py('엄!..하"안녕"..다')        # 'print("안녕")'
pyumsn.py_to_umsn('print("안녕")')             # '엄!..하"안녕"..다'
pyumsn.check_umsn("count ..은 1")             # [(1, 0, 5, "영어 이름 'count' 는 ...")]
pyumsn.run_file("안녕.umsn")                   # 실행, 종료 코드 반환
pyumsn.install_import_hook()                   # import 로 .umsn 모듈 불러오기
```

## 동작 방식

- 변환은 **토큰 단위**입니다. 문자열·주석은 원문 그대로, 이름·기호만 사전으로 바꿉니다. 그래서 줄 번호가 그대로라
  오류 위치가 엄슨 파일의 줄과 정확히 맞습니다.
- `pyumsn run` 은 엄슨을 파이썬으로 바꿔 **임시 `.py` 파일**을 만들고, 그것을 원래 `.umsn` 파일 이름으로 실행합니다.
  그래서 오류 추적 기록에 엄슨 소스 줄이 보입니다. 임시 파일은 실행이 시작되면 바로 지워집니다 (`--keep` 으로 보존).
- 파이썬 → 엄슨 → 파이썬 왕복은 원문과 같습니다 (기호어가 붙어서 헷갈릴 때만 공백 한 칸이 들어감).
  테스트에서 파이썬 표준 라이브러리 파일들로 확인합니다.

### PyPI 배포

1. `pyumsn/__init__.py` 의 `__version__` 을 올린다 (예: `1.0.1`). 같은 버전은 PyPI 에 다시 올릴 수 없다.
2. `main` 에 병합한 뒤 GitHub 에서 **Release** 를 만든다. 태그는 `v` + 버전 (예: `v1.0.1`).
3. `.github/workflows/publish.yml` 이 테스트 → 빌드 → PyPI 업로드를 자동으로 한다 (Trusted Publishing, 토큰 불필요).
   TestPyPI 로 먼저 시험하려면 Actions 탭에서 **Publish** 워크플로를 수동 실행하고 `testpypi` 를 고른다.

손으로 올릴 때는 `pip install -e ".[release]"`, `python -m build`, `twine check dist/*`, `twine upload dist/*`.

IDE 의 한국어 입력(IME)은 운영체제의 Tk 지원에 따릅니다.
