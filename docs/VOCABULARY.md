## 문자열 접두사

| 엄슨 | 파이썬 |
|---|---|
| `형"..."` | `f"..."` |
| `날"..."` | `r"..."` |
| `바"..."` | `b"..."` |
| `유"..."` | `u"..."` |
| `템"..."` | `t"..."` |

대문자 접두사는 앞에 `대` 를 붙입니다 (`대형"..."` = `F"..."`). 조합 가능: `형날`=`fr`, `날바`=`rb`.
